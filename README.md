# FUTURE_DS_03
# 📊 Marketing Funnel & Conversion Analysis

## 📌 Project Overview
This project analyzes a marketing funnel using a bank marketing dataset.  
The goal is to understand how customers move through different stages of the funnel:

Visitors → Leads → Customers

The analysis helps identify:
- Conversion rates
- Best-performing marketing channels
- Campaign effectiveness
- Funnel drop-offs
- Customer acquisition trends

This project is useful for:
- Digital Marketing Analytics
- Business Intelligence
- Sales Funnel Optimization
- Data Analytics Practice

---

# 📁 Dataset Used
Dataset Name: `bank-marketing.csv`

The dataset contains customer marketing campaign information such as:
- Contact channel
- Campaign details
- Customer response
- Day and month information
